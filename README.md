# RE:CRAFT

낡고 녹슨 기계·골동품을 작업대 위에서 360도 돌려 가며 **나사를 풀고, 녹을 벗기고, 부품을 교체해 새것처럼 되파는** 3D 분해·복원 시뮬레이션.

- 엔진: Unity 6000.3.13f1 · URP (Forward+) · Input System
- 플랫폼: Windows (PC)
- 현재 버전: v0.2.0 — 기획서 1단계(핵심 프로토타입) + 2단계(경제 루프·도구 업그레이드) + 아이템 7종·엔딩 + 튜토리얼

## 플레이 루프

의뢰 수주 / 폐품 경매 → 분해 → 녹 제거·세척 → 도색 → 파손 부품 교체 → 재조립 → 작동 테스트 → 납품·정산 → 도구 업그레이드

| 조작 | 동작 |
| :--- | :--- |
| 우클릭 드래그 | 물건 360도 회전 (트레이의 부품도 함께 회전) |
| 마우스 휠 | 줌 |
| `Tab` (누르고 있기) | X-Ray 스캐너 — 풀 수 있는 나사(노랑), 파손 부품(빨강), 녹슨 부품(주황) |
| `1` 손 | 클릭: 부품 분리 / 트레이 부품 드래그(또는 클릭): 스냅 조립 |
| `2` 드라이버 | 나사를 꾹 눌러 풀기 · 빈 구멍을 꾹 눌러 조이기 |
| `3` 녹 제거 · `4` 세척 · `5` 도색 | 좌클릭으로 문지르기 (95% 이상이면 자동 완료) |

## 구현된 것

- **데이터 기반 분해/조립**: 부품마다 `Under(...)`(먼저 떼어야 하는 부품)와 나사 위치만 적으면 순서가 자동으로 정해진다 — `Assets/_Project/Scripts/Items.cs`
- **마스크 페인팅 셰이더**: 부품별 마스크 텍스처(R 녹 / G 먼지 / B 도색)를 브러시로 칠해 실시간으로 Before → After — `Resources/Shaders/Surface.shader`, `Part.cs`
- **도구 3단계 × 4종**: 수동 드라이버 → 전동 드릴 → 마그네틱 임팩트 건 / 사포 → 와이어 브러시 → 샌드블라스터 / 헝겊 → 에어건 → 초음파 세척조 / 캔 스프레이 → 에어브러시 → 자동 도색 부스
- **공방 편의 업그레이드**: 부품 자동 발주 단말기, 자석 나사 정리함
- **아이템 7종**: 구형 라디오 · 토스터기 · 태엽 알람시계 · 손전등 (Tier 1) / 레트로 게임기 · 필름 카메라 (Tier 2) / 앤티크 오르골 (엔딩 유물)
- **경제**: 복원 의뢰 / 폐품 경매, 복원도(0~100%)에 따른 보수·명성(★), 도감, 저장
- **튜토리얼**: 첫 의뢰를 12단계로 안내 (회전 → X-Ray → 나사 → 분리 → 부품 주문 → 녹 제거 → 세척 → 도색 → 조립 → 테스트 → 납품 → 업그레이드). 실제 진행을 감지해 다음 단계로 넘어가며, 필요한 도구 버튼이 깜빡인다. 건너뛰기 가능, 게시판의 "튜토리얼 다시 보기"로 재시작 — `Tutorial.cs`
- 모든 메시·효과음·UI는 코드로 생성 (외부 에셋 없음)

## 열기 / 빌드

1. Unity Hub에서 이 폴더를 6000.3.13f1로 연다.
2. 메뉴 **RE-Craft → Setup Project** (씬·빌드 설정 생성) 후 `Assets/_Project/Scenes/Workshop.unity`에서 Play.
3. 메뉴 **RE-Craft → Build Windows** → `Builds/Windows/RECraft.exe`

배치 빌드:

```
Unity.exe -batchmode -quit -projectPath . -executeMethod ReCraft.EditorTools.ProjectSetup.SetupAndBuild -logFile build.log
```

## 개발용 실행 인자

| 인자 | 설명 |
| :--- | :--- |
| `-autoplay [-jobs N] [-item id]` | 수주 → 분해 → 복원 → 조립 → 테스트 → 납품을 자동 수행 |
| `-showcase [-item id]` | 모든 아이템을 조립/분해/복원 상태로 순회 |
| `-shots <dir>` | 단계별 스크린샷 저장 |
| `-tutorial N` / `-notutorial` / `-withtutorial` | 튜토리얼 단계 지정 / 끄기 / 봇 실행 시에도 켜기 |
| `-nosave` `-gold N` `-stars N` `-toollv N` `-timescale N` `-quitafter` | 테스트 보조 |
